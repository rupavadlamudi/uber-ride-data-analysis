# uber-ride-data-analysis# 🚕 Uber Data Analysis & Power BI Dashboard

## 📌 Overview

The **Uber Data Analysis & Power BI Dashboard** is an end-to-end Data Analytics project developed using **Python, SQL, and Power BI**. The project focuses on analyzing Uber booking data to understand booking trends, customer and driver cancellations, vehicle performance, payment methods, ratings, and pickup location patterns through interactive visualizations and business-driven insights.

This project helps identify key factors affecting bookings, cancellations, customer experience, and overall ride performance.

---

## 🎯 Project Objectives

* Analyze overall Uber booking trends and patterns.
* Monitor key booking and revenue-related KPIs.
* Analyze customer and driver cancellations.
* Identify major reasons for driver cancellations.
* Compare booking performance across vehicle types.
* Analyze driver rating distribution.
* Identify top pickup locations based on bookings.
* Analyze booking trends by date and hour.
* Compare booking value across different payment methods.
* Build an interactive Power BI dashboard for business decision-making.

## 📂 Dataset

The dataset contains Uber booking records with information related to bookings, customers, drivers, vehicles, cancellations, ratings, payments, locations, and booking values.

Key data fields include:

* Booking ID
* Booking Status
* Vehicle Type
* Pickup Location
* Drop Location
* Booking Value
* Payment Method
* Driver Rating
* Customer Rating
* Driver Cancellation Reason
* Customer Cancellation Reason
* Booking Date
* Booking Time
